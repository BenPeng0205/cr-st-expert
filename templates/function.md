# FUNCTION 模板

> 用途: 生成 `FUNCTION`

```iecst
/// 功能    : <功能描述>
/// 库依赖  : 暂无

{attribute 'hide_all_locals'}
FUNCTION F_<名称> : INT
VAR_INPUT
    iValue              : INT;          // 输入值
    iMin                : INT;          // 最小值
    iMax                : INT;          // 最大值
END_VAR

// === IMPLEMENTATION ===

/// =======================================================================
/// 名称      : F_<名称>
/// 功能      : <功能描述>
/// 库依赖    : 暂无
/// =======================================================================
/// 使用说明  : 1. 输入参数必须先完成边界确认
///           : 2. 函数只做无状态计算，不保存跨周期状态
/// =======================================================================

F_<名称> := LIMIT(
    MN := iMin,
    IN := iValue,
    MX := iMax
    );
```
