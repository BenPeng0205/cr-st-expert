# PROGRAM 模板

> 用途: 生成 `PROGRAM`

```iecst
/// 功能    : <功能描述>
/// 库依赖  : 暂无

PROGRAM PRG_<名称>
VAR
    fbController        : FB_<功能块>;
END_VAR

// === IMPLEMENTATION ===

/// =======================================================================
/// 名称      : PRG_<名称>
/// 功能      : <功能描述>
/// 库依赖    : 暂无
/// =======================================================================
/// 使用说明  : 1. PRG 作为任务入口和顶层调度对象
///           : 2. 调用 FB 时必须保持引脚语义匹配
///           : 3. 全局量必须通过 GVL 命名空间访问
/// =======================================================================

fbController(
    bEnable := TRUE
    );
```
