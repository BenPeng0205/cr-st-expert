# 最佳实践

## 1. 先规划 mirror 清单

先确定顶层 IEC 对象文件，再确定父 `FUNCTION_BLOCK` 内部的 `Method / Action / Property` 段落清单，最后写代码。

## 2. 先限边界再写逻辑

- 先处理 `NOT bEnable`
- 再处理 `bReset`
- 再进入主状态机

## 3. 让示例成为黄金样本

示例不应只是“能看懂”。它必须同时满足：

- 编码健康
- 规范一致
- 可通过自动校验
- 可作为回归基线

## 4. 把门禁当作产品一部分

对这个技能来说，`evals/run_delivery_gate.py` 不是附属脚本，而是发布定义的一部分。
