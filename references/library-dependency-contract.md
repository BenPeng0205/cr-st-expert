# 库依赖声明规范

文件头库依赖使用 LibraryId 或 LibraryId@Version，多个库用英文分号分隔。无外部库写“暂无”；未知版本只写库名并标注待确认，不填写虚构版本。

精确版本使用数字格式，同一批源码不混用同一个库的不同精确版本。不要写平台名、厂商名、“原生库”或 IDE 显示文本作为依赖标识。

写代码前在 generation_contract 中记录依赖声明，并与文件头一致。声明格式与用户提供的实际库资料核对。可选检查脚本可以根据已知符号线索提醒缺少声明，这些映射只是静态规则，不能证明库接口、安装状态或运行行为正确。

本技能不执行库下载、库管理器修改或工程验证；没有相关工具不阻断基础规范审查。外部库接口缺失时只检查已知规范，不编造领域调用。
