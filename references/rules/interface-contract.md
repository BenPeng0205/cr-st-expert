# 接口契约规则

> 适用场景：`VAR_INPUT / VAR_OUTPUT / VAR_IN_OUT`、FB 公共接口、GVL 共享数据。

## 1. 输入默认值

标量、时间、字符串和数组类 `VAR_INPUT` 应给出安全默认值。默认值必须让对象处于不动作或安全状态。

`ST_`、`E_`、`FB_` 和 `_REF` 等复合类型输入不强制写默认值；CODESYS 编译器会对部分结构体输入默认初始化产生告警，交付时应优先保持 0 错误、0 警告。

## 2. 输出语义稳定

`VAR_OUTPUT` 是调用方契约，确定后不得随意改名、改类型或改变语义。需要兼容性破坏时，应同步更新所有调用和文档。

## 3. 大结构体使用 `VAR_IN_OUT`

大型结构体、轴引用、缓冲区、共享数据应使用 `VAR_IN_OUT`，避免复制开销和状态不同步。

## 4. 指针输入谨慎使用

除非平台库明确要求，否则不要把指针作为普通业务接口。优先使用 `VAR_IN_OUT` 或结构体引用。

## 5. 输出不作为内部状态入口

调用方不应依赖 FB 内部变量。需要暴露的信息必须通过明确的 `VAR_OUTPUT` 或 Property 提供。
