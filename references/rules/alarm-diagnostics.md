# 报警与诊断规则

> 适用场景：错误码、报警结构、状态机故障上下文、HMI 诊断。

## 1. 错误码必须唯一

同一对象内错误码不得重复。错误码应按模块或状态段分区，便于 HMI、日志和远程诊断定位。

## 2. 错误上下文必须保留

进入错误状态时至少保留：

- 错误码
- 触发状态
- 关键输入或反馈
- 是否超时或外部中止

禁止只置位 `bError` 而不记录原因。

## 3. 报警与控制解耦

控制状态机负责安全状态转换；报警对象负责诊断展示和确认。不要让 HMI 报警确认直接改变设备控制状态。

## 4. 复位需要边界

复位必须清理错误输出和上下文，但不得清除仍然存在的真实故障。复位失败时应保留原错误或生成新的复位失败错误码。
